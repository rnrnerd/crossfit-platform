# Дизайн-система платформы

**Принцип: оформление всегда единое.** Организатор приносит контент — название,
логотип, описание, комплексы. Цвета, шрифты и компоненты принадлежат платформе.
Логотип события живёт внутри карточки как картинка, а не как тема оформления.

Паттерны взаимодействия вдохновлены Circle21 (структура лидерборда, экран
захода), но визуальный язык — собственный: чужую палитру не копируем, иначе
платформа не будет узнаваемой.

---

## Палитра

Тёмная база — соревнования проходят в залах с приглушённым светом, на телефоне
тёмный экран читается лучше и меньше слепит.

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#0e0f12` | фон приложения |
| `--surface` | `#16181d` | карточки |
| `--surface2` | `#1d2027` | вложенные блоки, поля ввода |
| `--border` | `#2a2e37` | границы, разделители |
| `--text` | `#f2f3f5` | основной текст |
| `--hint` | `#8b909c` | подписи, второстепенное |
| `--gold` | `#f2c440` | **фирменный акцент**: активное состояние, места, ключевые числа |
| `--accent` | `#e0533d` | предупреждения, снятие с соревнования |
| `--green` | `#3fae6b` | подтверждения, успешное сохранение |

Золотой — преемственность с «Битвой за Херсонес» и отличие от оранжевого Circle21.

## Типографика

- **Oswald** — заголовки, имена атлетов, числа (места, баллы, время). Узкий,
  плотный, спортивный; хорошо читается крупно.
- **Inter** — интерфейсный текст, описания, подписи.
- Заголовки и имена — **капсом**, с трекингом.
- Числа всегда крупнее и жирнее окружающего текста: в соревновании смотрят
  на цифры.

## Компоненты

**Карточка** — `border-radius: 14–16px`, фон `--surface`, граница `--border`,
зазор между карточками 10–12px. Основная единица интерфейса.

**Строка участника** (лидерборд, старт-лист):
`место (медаль у топ-3) → аватар → имя капсом → результат → шеврон раскрытия`.
Лидер выделяется золотой обводкой карточки.

**Пилюли-фильтры** — скруглённые, активная заливается золотым с тёмным текстом.
Разные группы фильтров различаются заливкой и контуром, а не разными цветами:
пестрота ломает единство.

**Нижнее меню** — фиксированное, текст без иконок-эмодзи, активный пункт —
золотая пилюля. Учитывает безопасную зону снизу.

**Поля ввода** — крупные (минимум 44px по высоте), маски по типу данных
(`мм:сс`, кг, повторы). Судья вводит на бегу, в шуме, иногда в перчатках.

## Правила

1. **Числа — главное.** Место, баллы, время должны читаться с расстояния вытянутой руки.
2. **Минимум мелкого текста.** Если подпись меньше 11px — её, скорее всего, можно убрать.
3. **Одно действие — одна кнопка.** На экране судьи не должно быть кнопок,
   которые что-то удаляют.
4. **Состояние всегда видно.** Загрузка, «не отправлено», «сохранено» —
   пользователь не должен гадать.
5. **Пустые состояния объясняют, что делать**, а не просто «нет данных».
6. **Всё на русском**, включая служебные сообщения.
