# Кроссфит-платформа

Telegram Mini App для кроссфит-соревнований: календарь стартов, заявки,
профиль атлета и проведение турнира (лидерборд, комплексы, заходы, расписание).

Backend — aiohttp + PostgreSQL, фронт — один `index.html`.
Схема данных описана в [SCHEMA.md](SCHEMA.md), визуальный язык — в [DESIGN.md](DESIGN.md).

## Переменные окружения

| Переменная     | Зачем                                                             |
|----------------|-------------------------------------------------------------------|
| `DATABASE_URL` | PostgreSQL. На Railway подставляется автоматически.               |
| `BOT_TOKEN`    | Токен бота из BotFather. Нужен для проверки подписи `initData`.   |
| `WEBAPP_URL`   | Публичный адрес приложения.                                       |
| `DEV_TG_ID`    | Только для локальной разработки: вход без Telegram под этим tg_id. |
| `PORT`         | Порт. На Railway подставляется автоматически, локально — 8080.     |

`DEV_TG_ID` на боевом стенде задавать нельзя: он пускает в приложение
без Telegram, под чужим профилем.

## Деплой на Railway

1. Создать проект и подключить этот репозиторий — сборка идёт по `Procfile`,
   версия Python берётся из `.python-version`.
2. Добавить в проект плагин PostgreSQL. `DATABASE_URL` появится сам.
3. Задать `BOT_TOKEN` и `WEBAPP_URL` в переменных проекта.
4. Таблицы создаются при первом старте — миграции идут в `init_db()`.

## Бот

Отдельного процесса бота нет: `backend.py` поднимает только веб-сервер.
Бот нужен как точка входа и как источник `BOT_TOKEN`, поэтому вся его
настройка делается в BotFather:

- `/newbot` — создать бота, получить токен;
- `/mybots` → бот → Bot Settings → Menu Button → задать адрес стенда.

## Демо-данные

`seed_demo.py` заливает 22 атлета, 3 события, дивизионы, заявки, комплексы,
результаты и заходы. Требует Pillow (генерирует аватарки и баннеры), поэтому
в `requirements.txt` его нет — запускать локально, указав нужную базу:

```bash
DATABASE_URL='<адрес базы>' python seed_demo.py
```

## Локальный запуск

```bash
pip install -r requirements.txt
DATABASE_URL='postgresql://localhost/crossfit_platform' DEV_TG_ID='<ваш tg_id>' python backend.py
```
